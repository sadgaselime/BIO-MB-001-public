## 2. Series Matrix vs normalized file — full comparison (VERIFIED)

All comparable values were compared, not a subset: 38,323 probes × 329 samples = **12,608,267 values,
0 differences** (maximum absolute difference 0.0). The probe sets are identical once the split record
is re-joined. The Series Matrix is therefore the normalized file **minus** the extra column
`4856076038_D`, with GSM column labels. The normalized file's column order differs from the Series
Matrix (immaterial; columns were matched by GEO title).

## 3. Malformed row in the normalized file (VERIFIED)

Line 30,881 contains only `ILMN_2315789` followed by a line break. Its 330 values are on line 30,882,
whose ID field is empty. Re-joined in memory, the values equal the Series Matrix values for
ILMN_2315789 in all 329 samples (difference 0). The record is complete and recoverable; nothing was
lost. The probe is annotated to PTPRD (Entrez 5789). **Impact on the intended analysis: none if the
Series Matrix is used**, since its copy of the record is intact.

## 4. Extra column `4856076038_D` (VERIFIED facts, then INTERPRETATION)

- VERIFIED: present in both supplementary files; absent from all 329 GEO sample records of GSE63060
  (and from all retrieved GSE63061/GSE140829 records). It is not a copy of any GEO sample: its best
  Pearson correlation with a GEO sample is 0.984, versus a typical best correlation of 0.986 between
  two GEO samples. All other 11 positions on chip 4856076038 are GEO samples. Its value range
  (7.2045–15.0498) is identical to every GEO sample's range.
- INTERPRETATION: a 330th array was hybridized and normalized together with the cohort, then not
  deposited as a GEO sample (for example a failed-QC array or a withdrawn participant). Consequence:
  the 329 normalized profiles were produced in a normalization that included this array, so they cannot
  be reproduced exactly from the 329 deposited samples alone. The effect is expected to be small (1 of
  330 arrays), but it is not quantified.
- **Impact:** it has no phenotype record, so it cannot enter any labelled analysis. If either
  supplementary file were used, this column would have to be excluded. The Series Matrix already omits it.

## 5. Non-normalized file — the three empty-header columns

Method (content-based; column counts and positions were **not** used): every non-normalized column
was rank-compared with every normalized column over the 38,323 shared probes (Spearman correlation
plus an exact per-probe rank comparison and a monotonicity check).

- VERIFIED validation: for all 327 named columns, the best match is the sample's own normalized column
  (Spearman 1.000000, 0 probes changing rank, 0 monotonicity violations, matching tie structure). No
  named column correlates above 0.894 with any other sample; the smallest gap between the best match
  and the runner-up is 0.106.
- VERIFIED result: each empty-header column is rank-identical (Spearman 1.000000, 0 rank differences,
  identical tie counts) to exactly one normalized column, and those three columns are precisely the
  three that have no named non-normalized column:

| File column | Rank-identical to | GEO record | Diagnosis | Runner-up Spearman | GEO "included in case-control study" |
|---|---|---|---|---|---|
| 317 | `4856050008_B` | GSM1539292 | AD | 0.837 | no |
| 323 | `4856050008_K` | GSM1539294 | AD | 0.866 | no |
| 329 | `4856050048_A` | GSM1539298 | AD | 0.833 | no |

- INTERPRETATION: the empty headers are almost certainly an export/labelling defect for these three
  arrays. The mapping is **inferred from data content** — strongly supported, but not documented by
  the submitter. If the non-normalized file is ever used, record these three labels as inferred.
- Column order gives no usable signal (the non-normalized order follows neither the GSM order nor the
  normalized-file order).

## 6. Processing history and scale

- REPORTED (GEO): every GSM states only "Using LUMI package in R". The series links PubMed 26343147.
  No transformation, normalization or filtering parameters are given in the GEO records.
- VERIFIED:
  - the normalized values are on a log-like scale (7.20–15.05); the median Pearson correlation between
    log2(non-normalized) and normalized is 0.995;
  - within every sample, the normalized values are a strictly rank-preserving function of the
    non-normalized values (0 rank changes across 38,323 probes in all 330 columns), so the normalized
    data derive from these non-normalized signals by per-sample monotone transformation(s);
  - all 330 samples share exactly the same minimum (7.2045) and maximum (15.0498); their sorted
    profiles differ by at most 0.0066 — near-identical but **not** exactly quantile-normalized;
  - the normalized floor (7.20) is above log2 of the lowest raw signal (about 6.5), so the transform
    is not plain log2;
  - 10,480 probes present in the non-normalized file are absent from the normalized file; all have
    mean raw signal ≤ 121.6 (low-expression probes).
- INTERPRETATION: consistent with lumi's typical workflow (a variance-stabilizing or log-like
  transform followed by robust spline or quantile-type normalization) and a detection-based probe
  filter. **The exact transform, normalization method and filter threshold cannot be verified** from
  the files: no detection p-values were deposited, and GEO gives no parameters.
- The non-normalized file holds summarized per-probe signals (not bead-level or instrument data). The
  `GSE63060_RAW.tar` holds only the platform annotation manifest, so no raw instrument-level data are
  available for this series.
- Implication: the Series Matrix values are already transformed and normalized; they must **not** be
  normalized again.

## 7. Platform annotation

- Source: Illumina BGX manifest `GPL6947_HumanHT-12_V3_0_R1_11283641_A.bgx.gz`, read in memory from
  `GSE63060_RAW.tar` (member SHA-256 `5d1c743a…`), dated 6/5/2008, content version 1.0, 48,803 probes
  plus 784 controls. The GPL6947 record describes the content as NCBI RefSeq Build 36.2, Release 22.
  The full GPL6947 data table was not downloaded (network not used), so no GEO-side annotation
  comparison was made.
- Coverage of the 38,323 analysis probes (VERIFIED):
  - all 38,323 are present in the manifest;
  - 30,061 (78.4%) have a gene symbol and 29,372 (76.6%) an Entrez Gene ID; 689 have a symbol but no
    Entrez ID;
  - 4,684 symbols are provisional `LOC…`/`HS.…` placeholders;
  - sources: 30,060 RefSeq, 8,262 UniGene, and 1 "ILMN_Controls" probe (ILMN_2038773, UBC).
- Many-to-one and ambiguity (VERIFIED):
  - 21,696 distinct symbols; 5,677 symbols have more than one probe, covering 14,042 probes (maximum
    12 probes per symbol);
  - 10 symbols map to more than one Entrez ID; 164 Entrez IDs carry more than one symbol;
  - each probe has exactly one symbol field (no multi-gene probe entries).
- The BGX column named `Obsolete_Probe_Id` contains gene-synonym strings rather than probe IDs; do not
  rely on it.
- UNRESOLVED: the 2008 annotation is out of date. Mapping probes to current gene identifiers needs a
  pinned, versioned modern annotation, for example re-mapping the probe sequences (included in the
  BGX) or a versioned Illumina annotation package. That choice should be prespecified before any
  gene-level analysis, together with the rule for genes measured by several probes.

## 8. Exclusions and their impact

- **Samples (Series Matrix):** no file-level exclusion is required; all 329 columns have a GEO record
  and a diagnosis. The AD-versus-healthy-control contrast uses AD (145) and HC (104); the 80 MCI
  samples are outside that contrast but were part of the joint normalization. Nothing has been
  removed.
- **Features (Series Matrix):** no duplicates, no missing values, and no malformed records; the probe
  set already reflects the submitter's undocumented low-signal filter.
- **If the normalized file were used:** re-join the split record and exclude `4856076038_D`.
- **If the non-normalized file were used:** exclude `4856076038_D`, and the three AD columns depend on
  inferred labels.
- **Scientific decision not settled by file quality (UNRESOLVED):** GEO's characteristic
  "included in case -control study" is **yes** for only 49/145 AD, 67/104 controls and 39/80 MCI
  (no: 96 / 37 / 41). Its meaning is not documented in the GEO records; it may define the original
  study's matched case-control subset. Whether the primary analysis uses all AD versus HC
  (145 vs 104) or the flagged subset (49 vs 67) must be decided and prespecified. All three samples
  recovered in section 5 are "no".
- Reported leads (published outlier exclusions or ID mismatches) remain unchecked: no sample IDs have
  been entered from the publications. INTERPRETATION: the extra column and the three empty headers
  are plausible sources of a reported "ID mismatch", but this is not verified.
